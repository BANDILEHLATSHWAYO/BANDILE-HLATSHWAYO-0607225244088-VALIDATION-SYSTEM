# BANDILE-HLATSHWAYO-0607225244088-VALIDATION-SYSTEM
Data Validation System — Java Swing
Project Description
The Data Validation System is a Java Swing desktop application developed for the Advanced Programming II assignment at Gauteng City College.
The system captures personal information through a graphical user interface and validates each field before the information is accepted.
Features
* Name and surname validation
* ID / student number validation
* Date of birth validation
* Gender selection using radio buttons
* Contact number validation
* Email address validation
* Presence checks
* Type checks
* Length checks
* Format checks
* Range checks
* Clear error messages
* Save functionality
* Clear functionality
* Exit functionality
* User-friendly Java Swing interface
Technologies Used
* Java
* Java Swing
* JFrame
* JPanel
* JTextField
* JRadioButton
* JButton
Validation Rules
Name
* Cannot be empty
* Must contain 2–30 characters
* Allows letters, spaces, apostrophes and hyphens
Surname
* Cannot be empty
* Must contain 2–30 characters
* Allows letters, spaces, apostrophes and hyphens
ID / Student Number
* Cannot be empty
* Numbers only
* Must contain 8–13 digits
Date of Birth
* Cannot be empty
* Must use DD/MM/YYYY
* Cannot be a future date
* Age must be between 1 and 120 years
Gender
* One option must be selected
Contact Number
* Cannot be empty
* Numbers only
* Must contain exactly 10 digits
Email
* Cannot be empty
* Must follow a valid email format
* Maximum 100 characters

How to Run
NetBeans

2. Select File → Open Project.
3. Select the DataValidationSystem folder.
4. Open Main.java.
5. Right-click Main.java.
6. Select Run File.
